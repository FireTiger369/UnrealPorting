Unreal Porting is a tool used for looking through unreal engine games and being able to get textures and all textures for any material or material instance!

This is a new app to build off of what FModel has done a little and to include new things such as getting all textures in a material and mip level exporting from textures coming in a future update!

For the time being we are aware of issues such as Material Functions not being readable as well as some file paths in main folders do not direct to the right assets leading into errors. We will continue to work and provide updates as needed!
This also has a built in updater feature so no need to redownload the app everytime a update comes out however you are welcome to skip updates if you wish and go to different build versions in releases until they get wiped.
